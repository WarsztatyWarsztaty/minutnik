Co miał robić minutnik?
1. Co robi?
Program pozwala użytkownikowi uruchomić minutnik.
Program pozwala zatrzymać odliczanie.
Program pozwala zresetować minutnik.
Program wyświetla pozostały czas.
Program pokazuje liczbę ukończonych cykli.
Program umożliwia korzystanie z czasu pracy i przerwy.
2. Czego nie robi?
Program nie wymaga zakładania konta.
Program nie synchronizuje danych z internetem.
3. Po czym poznam, że działa?
Kiedy nacisnę Start, to rozpocznie się odliczanie.
Kiedy nacisnę Pauza, to odliczanie zostanie zatrzymane.
Kiedy nacisnę Reset, to minutnik wróci do początkowego stanu.
Kiedy zakończy się czas pracy, to rozpocznie się przerwa.
Kiedy zakończy się przerwa, to minutnik przygotuje kolejny cykl.
4. Do ustalenia
Czy reset powinien zerować licznik cykli?
Czy historia cykli powinna być zachowywana po zamknięciu aplikacji?
Czy użytkownik powinien mieć możliwość zmiany wszystkich parametrów minutnika?

Program domyślnie ustawia czas pracy na 25 minut, a czas przerwy na 5 minut.
Program pozwala użytkownikowi zmieniać długość czasu pracy i przerwy w oknie.
Program wyświetla czas w formacie mm:ss.
Program posiada jeden przycisk Start/Pauza oraz osobny przycisk Reset.
Interfejs programu jest w języku polskim, a nazwy w kodzie w języku angielskim.
Program nie korzysta z dodatkowych bibliotek.
